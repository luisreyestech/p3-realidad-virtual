P3 · Realidad virtual con A-Frame
Autor: Luis Reyes

La página ofrece una imagen panorámica de 360 grados y un vídeo inmersivo sobre la Tierra. Utiliza los botones para cambiar de experiencia y arrastra el ratón para mirar alrededor. El vídeo se inicia al pulsar el botón de reproducción.

Para usar el proyecto, abre la página desde un servidor web o publícala en GitHub Pages. Se necesita conexión a internet para cargar A-Frame y los recursos multimedia.
